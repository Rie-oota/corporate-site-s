# 株式会社S 公式ホームページ

## 概要

会社設立に伴い、株式会社Sの公式ホームページを制作しました。
企業情報や事業内容を分かりやすく伝えることを目的とし、
シンプルで視認性の高い構成を意識しています。

## 担当範囲

- デザイン
- コーディング

## 制作期間

約2か月

## 使用技術

- HTML
- CSS
- JavaScript
- jQuery

## デザイン・実装のポイント

- セマンティックHTMLを用いた構造設計
- レスポンシブ対応（PC / タブレット / スマートフォン）
- UI制御やアニメーションによる操作感の向上
- 青・白・黄を基調とした、使いやすくスッキリとした配色設計
